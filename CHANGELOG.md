# Changelog
All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-10-08
### Added
- Core GUI widget framework using GTKmm and PyGObject.
- Dual X11 (xrandr) and Wayland (D-Bus) display environment switcher engine.
- Automated PulseAudio/PipeWire audio routing extensions (`audio_switcher.py`).
- Full automated CI/CD deployment logic for GitHub Actions release builds.
