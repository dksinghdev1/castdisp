# castdisp 🚀

**castdisp** (Cast Display and Audio) is a universal multi-monitor setup utility and GUI widget for Linux desktops. It acts like the `Super + P` display projector layout switcher on Windows, allowing users to cycle between screen layouts seamlessly on both **Wayland** and **X11** display servers, with integrated automated HDMI audio routing.

## Installation

### Via Snap Store
```bash
sudo snap install castdisp
```

### Via Ubuntu APT PPA
```bash
sudo add-apt-repository ppa:dharmendra30/castdisp
sudo apt update
sudo apt install castdisp
```
